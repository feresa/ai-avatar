# 踩坑紀錄

做 AI 分身短影音時遇過的問題、原因和解法。遇到怪問題先來這裡找，修好新的坑也記在這裡。

## 最短流程（照這個做，大部分的坑都避開了）

1. **Colab「AI分身工作室」**：`SCRIPT_FILE` 填講稿 → 設定 → 安裝 → 產生聲音（聽過）→ 做影片
   - 執行階段選 **G4**（或 A100 / L4），不要用 T4
   - 做好的影片旁邊會自動多一個同名 `.txt`（念稿），剪片時會自動抓來當字幕
2. **Mac**：`npm run panel` → 🚀 一鍵做片：填專案名、貼影片路徑 → 按「一鍵做片」
   - 或終端機：`npm run make -- challenge-d2 影片路徑`
   - 中途卡住，修好再按一次，做過的步驟會跳過
3. 看成品，想改什麼在控制台第 3 區「還想改什麼」寫下來，交給 Claude 跑，再按「一鍵完成目前這支」

## Colab（做分身影片）

| 症狀 | 原因 | 解法 |
|---|---|---|
| 對嘴時 `CUDA out of memory`，GPU 總共 14.56 GiB | 分到 T4。512 高畫質對嘴模型要 18GB 以上 | 執行階段 → 變更執行階段類型 → G4 / A100 / L4。換了要重跑「安裝」 |
| `找不到 .../MyDrive/AI自動剪片/AI分身素材/studio_tools.py`（用別的帳號跑） | 共用的資料夾只在「與我共用」，Colab 只看得到「我的雲端硬碟」 | 對方在「與我共用」對 `AI自動剪片` 按右鍵 → 整理 → 新增捷徑 → 我的雲端硬碟（放最上層）。共用時要給「編輯者」 |
| 掛載後「我的雲端硬碟最上層：[]」 | 掛載的帳號沒有捷徑，或登入錯帳號 | 用被共用的帳號建捷徑，`drive.mount(..., force_remount=True)` 重新掛載 |
| 聲音悶悶的、不清楚 | 參考聲音品質差（`我的聲音_20261019_20s.wav` 推算只有 8kHz） | 用原始錄音或重錄 10~15 秒（安靜房間、手機距離 20 公分）。目前用 `我的聲音_261029.m4a` |
| 聲音不像、口音怪 | 參考文字辨識錯（「呼吸法」被聽成「胡錫進」） | `VOICE_REF_TEXT` 填正確文字，一字不差；只截到一半就刪到同一個地方 |
| 斷句怪：「第一件事是 不是拿手機」「想 跟我一起挑戰」 | 模型把單字黏錯邊 | 另存一份念稿（`day1_念稿.txt`），在要停的地方加逗號；單字開頭的句子改說法（「想跟我」→「要不要跟我」）。講稿原檔不要改，字幕還要用 |
| 改了講稿，念出來還是舊的 | `AUDIO_FILE` 有填，直接用舊聲音 | 重做聲音時 `AUDIO_FILE` 清空 |
| 分身動作很少、很呆 | LatentSync 只改嘴巴，頭和手都照搬底片 | 換動作多的底片，或 `BASE_START_SEC` 跳到動作多的段落；剪片時用推近、轉場、貼圖補 |

## Mac（剪片）

| 症狀 | 原因 | 解法 |
|---|---|---|
| 字幕有錯字 | 沒給講稿，用語音辨識 | 影片旁邊放同名 `.txt`，或一鍵做片時貼講稿。已經做好的：`npm run align -- 專案名 講稿檔` |
| 要跑 align 才發現專案沒有講稿 | 建專案時沒帶講稿 | 已修：建專案會自動抓影片旁同名 `.txt`；Colab 新版會自動存 |
| 字幕比講話慢 | 語音辨識的時間偏晚 | `npm run lead -- 專案名` 自動量（一鍵做片會自動跑） |
| `lead` 只量到 1~2 句 | 字幕每個字頭尾相連，判斷不出句子開頭 | 已修：改用標點分句 |
| `npm run matte`：找不到 Remotion 內建的 ffmpeg | Mac 上 Remotion 的 ffmpeg 要設 `DYLD_LIBRARY_PATH` | 已修。還是不行就 `brew install ffmpeg`，會自動改用 |
| 去背很慢 | Mac 用 MPS 約 4 格/秒，40 秒影片約 5 分鐘 | 正常；趕時間用雲端硬碟的 `AI去背.ipynb`，再 `npm run matte -- 名稱 --file 下載的_去背.webm` |
| 輸出卡在某一格：`Timeout while extracting frame` | 剪貼、破框那一格突然多掛一層影片，Mac 同時解碼太多 | 已修：提早 1 秒載入、預設同時 2 格。還是卡就 `RENDER_CONCURRENCY=1 npm run render -- 名稱` |
| 控制台「交給 Claude」看起來卡住 | 舊版要全部做完才一次印出來 | 已修：即時顯示 Claude 在做什麼。規劃一支片約 1~10 分鐘 |
| `git pull` 被擋：本機有改過的檔案 | 本機改了 README / package.json 等 | 先 `git stash` 再 pull，或把改的推上去 |
| 控制台改版沒生效 | 控制台開著時 pull，跑的還是舊程式 | Ctrl+C 關掉，`npm run panel` 重開 |
| Mac 上的 Claude 不肯推影片到 GitHub | 影片不進 git（`.gitignore` 擋掉） | 本來就不用推影片。規劃畫面直接在 Mac 上讓 Claude 做（一鍵做片），不用傳 GitHub |
| 專案名有中文就失敗 | Remotion 只接受英文、數字、`-` | 用 `challenge-d1` 這種名字 |
| 開場小膠囊出現「每個特效都是 Claude 剪的」 | 新專案的預設值 | 已修：預設空白，Claude 規劃時會照內容寫 |

## 寫講稿的小技巧（給 TTS 念）

- 想停的地方加「，」，要停久一點用「。」
- 一句太長會越念越快，拆成兩句
- 數字寫國字：「10 次」→「十次」
- 破音字念錯就換同音字，但只改在念稿，講稿原檔保持正確（字幕用）
